1 · 问题陈述

开发者使用 Claude Code 在本地执行编码任务时面临四个核心问题：

问题影响
本地资源占用大AI Agent 运行时消耗大量 CPU/内存/磁盘，导致本地机器变卡，影响其他工作
交互体验受限本地 CLI 交互模式不适合长时间自主执行，开发者被迫等待或频繁干预
无法安全授权要让 Agent 产出高质量代码需要最高权限，但本地环境包含敏感文件和配置，风险不可控
缺乏任务抽象每次执行都是临时性的，无法定义权限边界、工具集、skill、预算、目标、成功标准，也无法复用配置

团队使用 DevOps 平台管理需求任务和代码仓库，但目前没有工具能将 DevOps 平台上的需求任务自动交给 AI Agent 在隔离环境中完成。

2 · 解决方案

构建一个 Agentic Coding Platform，开发者从 DevOps 平台选择需求任务，平台调度 Agent 在隔离沙箱中自动完成编码、自检、提交、CI/CD 验证，最终创建 MR 等待开发者 Review。

Issue in, MR out.

2.1 核心机制

机制说明
Task 抽象基于 Template 定义任务的权限、工具集、skill、预算、成功标准。Template 可复用、可参数化
沙箱隔离每个任务在独立 Docker 容器中执行，Agent 拥有完全权限但不影响开发者本地环境
身份绑定沙箱继承用户身份，Agent 的所有对外操作（Git push、CI/CD 访问）代表该用户
双层反馈闭环内层自检（Template 定义，始终生效）+ 外层 CI/CD 反馈（MCP Server，就绪后生效）
DevOps 集成控制面直接调 DevOps API（拉取任务列表、创建 MR）；执行面 Agent 通过 MCP Server 按需访问 DevOps

2.3 双层反馈闭环

内层：Agent 自检（始终生效）

Agent 在沙箱内部自主完成编码后，按 Template 定义的标准自检：

  • 运行项目已有测试用例（如测试通过率 > 80%）
  • 执行 lint、格式化等代码规范检查
  • 检查关键文件是否生成/修改
  • 自检不通过 → 分析问题 → 修复 → 重新自检

不依赖任何外部系统，Agent 自身能力范围内完成。自检通过后 Push 代码。

外层：CI/CD 反馈（MCP Server 就绪后生效）

Agent Push 代码后，通过 MCP Server 获取 CI/CD 结果：

  • 通过 DevOps MCP Server 获取流水线执行结果
  • 获取测试通过率、扫描问题、构建状态
  • CI/CD 有失败 → 分析问题 → 修复 → 重新 Push
  • CI/CD 全部通过 → 创建 MR

依赖 DevOps MCP Server 开发完成。MCP Server 就绪前，以内层自检为主，自检通过即可创建 MR。

2.4 一阶段约束

约束说明
单 Provider只支持 Claude Code CLI，不提供 Provider 选择（Provider 管理代码保留）
单 Agent每个任务一个 Agent，不支持多 Agent 协作
FIFO 调度简单队列，不支持优先级、抢占
API Key 认证一阶段 API Key，后续接公司 SSO
单租户运行多租户代码保留，一阶段单租户运行
预置模板3 个预置模板（编码任务/Bug 修复/代码重构），不支持自定义模板。模板定义成功标准
Web 通知仅 Web 推送通知，不做 IM/邮件
双 Runtime本地 Docker + 远程 K8s 双运行时，支持不同开发环境

4 · 功能模块设计

#模块类型核心职责
1Auth Middleware新建API Key 校验 → 注入 user_id/tenant_id 到 context；预留 SSO 扩展点
2Scheduler Dispatcher修改给 scheduler.Start() 加 goroutine 消费循环：Dequeue → rate limit → executor.Execute()
3DevOps Integration Service新建封装 DevOps API：拉取用户任务列表、获取任务详情、创建 MR、获取仓库信息
4Credential Manager新建用户凭证（Git token、DevOps token）加密存储 + 沙箱启动时注入
5Template Preset + Task Resolution修改预置 Template（coding-task/bug-fix/refactor）+ DevOps 任务 + Template → Task 解析
6Metrics Implementation修改替换 stub 为实际 DB 查询（任务统计、资源使用、队列状态）
7WebSocket Auth修改连接时校验用户身份（ws://?token=api_key），按 user scope 推送
8Frontend UI新建（后补）工作台 + 任务列表 + 任务详情 + Issue 列表 + 设置（React + Ant Design）

4.1 Deep Modules

DevOps Integration Service

封装所有 DevOps API 复杂度。

接口：ListTasks(userID), GetTaskDetail(taskID), CreateMR(repo, branch, title)

Mock DevOps API 即可独立测试。

Credential Manager

封装凭证存储加密 + 沙箱注入。

接口：Store(userID, type, value), InjectToSandbox(taskID, config)

Mock sandbox 即可独立测试。

Scheduler Dispatcher
